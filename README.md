# SistemaRestaurante

## IMPORTANTE
Para tener una copia de la BD, PRIMERO se debe ejecutar el script Login_SistemaRestaurante.sql antes de ejecutar SistemaRestaurante.bak. Esto es para asegurar que primero exista el login antes de cargar la copia de seguridad de la base de datos para una mayor facilidad de integración con SQL Server Management Studio.
